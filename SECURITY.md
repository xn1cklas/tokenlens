# Security Policy

## Supported Versions

Security fixes target the latest major version of TokenLens.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately by emailing hi@n1cklas.com. Include the affected package, version, reproduction steps, impact, and any suggested remediation. Do not open a public GitHub issue for sensitive reports.

We will acknowledge valid reports as soon as practical, coordinate a fix, and publish patched packages when needed.
