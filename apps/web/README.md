# TokenLens Web

The official website for TokenLens - built with Astro and Starlight.

## Structure

- `/` - Homepage with install button
- `/initiative` - Explanation of why TokenLens exists
- `/docs/` - Starlight documentation

## Development

```bash
pnpm dev
```

## Build

```bash
pnpm build
```

## Preview

```bash
pnpm preview
```

## Features

- 🎯 Minimal, focused homepage with one-click install
- 📖 Comprehensive documentation via Starlight
- 🎨 Clean, modern design with dark mode support
- ⚡ Fast, static site generation with Astro
- 🎊 Delightful interactions with confetti on copy
